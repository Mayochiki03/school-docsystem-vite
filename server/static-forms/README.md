# โฟลเดอร์เก็บฟอร์ม PDF แบบคงที่ (Static PDF Forms)

โฟลเดอร์นี้สำหรับเก็บไฟล์ PDF ของฟอร์มที่ระบบยังไม่รองรับการกรอกแบบดิจิทัล (เช่นฟอร์มราชการที่ซับซ้อนมาก
และต้องส่งออกหน่วยงานภายนอก) — ผู้ใช้งานจะดาวน์โหลด/สั่งพิมพ์ไปกรอกด้วยมือแทน

## วิธีใช้

1. เอาไฟล์ PDF มาวางไว้ในโฟลเดอร์นี้ (server/static-forms/) — **ตั้งชื่อไฟล์เป็นภาษาอังกฤษ ตัวเลข ขีดกลาง (-)
   หรือขีดล่าง (_) เท่านั้น ห้ามมีช่องว่างหรือภาษาไทยในชื่อไฟล์** เช่น `edu-welfare-child-kt16.pdf`
2. ไปที่หน้า "ประเภทเอกสาร" ในระบบ → สร้าง/แก้ไขประเภทเอกสาร → ตั้ง "ชนิดฟอร์ม" เป็น
   "ไฟล์ PDF คงที่ (ยังไม่รองรับกรอกดิจิทัล)" → พิมพ์ชื่อไฟล์ที่ตั้งไว้ในข้อ 1 ให้ตรงกันเป๊ะ (รวมนามสกุล .pdf)
3. บันทึก — ระบบจะดึงไฟล์นี้มาแสดงตัวอย่าง + ให้ดาวน์โหลด/สั่งพิมพ์ได้ทันทีที่มีคนเลือกประเภทเอกสารนี้

## ชื่อไฟล์ที่แนะนำสำหรับ 2 แบบที่เจอตอนพัฒนา v2.2.0

- ใบเบิกเงินสวัสดิการเกี่ยวกับการศึกษาบุตร (กท.16 ช.) → `edu-welfare-child-kt16.pdf`
- ใบเบิกเงินสวัสดิการค่ารักษาพยาบาล (กท.4 ช.) → `medical-welfare-kt4.pdf`

(ชื่อไฟล์ปรับเป็นอย่างอื่นก็ได้ ขอแค่ตั้งในหน้า "ประเภทเอกสาร" ให้ตรงกับชื่อไฟล์จริงเป๊ะๆ)

## ข้อจำกัด
- รองรับเฉพาะไฟล์ .pdf เท่านั้น
- ขนาดไฟล์แนะนำไม่เกิน 20MB ต่อไฟล์ (ไฟล์ใหญ่มากจะโหลดช้าตอนพรีวิว)
- ไฟล์ในนี้ **ไม่ได้อยู่ในระบบสำรองข้อมูลอัตโนมัติ** (backup ระบบสำรองเฉพาะ data/ กับ uploads/) — แนะนำเก็บ
  ไฟล์ต้นฉบับไว้อีกที่หนึ่งด้วย
