# server/fonts/ — ฟอนต์สำหรับแปลงไฟล์ Word เป็น PDF

โฟลเดอร์นี้ไว้ใส่ไฟล์ฟอนต์ (.ttf / .otf) ที่ **เครื่องเซิร์ฟเวอร์** ต้องมี เพื่อให้ LibreOffice (ที่ใช้แปลงไฟล์
Word เป็น PDF สำหรับฟิลด์ "แนบไฟล์เอกสาร") render เอกสารออกมาถูกต้อง ไม่ใช้ฟอนต์สำรอง (fallback) ที่หน้าตา
ต่างจากต้นฉบับ

## ทำไมต้องสนใจเรื่องนี้

- การแปลง Word → PDF เกิดขึ้นที่ **เซิร์ฟเวอร์** (ไม่ใช่เครื่องผู้ใช้) — LibreOffice บนเซิร์ฟเวอร์ต้องมีฟอนต์
  ที่เอกสารต้นฉบับใช้ (เช่น "TH Sarabun New") ติดตั้งอยู่ ไม่งั้นจะ render ด้วยฟอนต์อื่นแทนแบบเงียบๆ
  (หน้าตาเพี้ยนจากต้นฉบับ ระยะบรรทัด/ความยาวข้อความเปลี่ยน อาจทำให้ตัดหน้าไม่ตรงจุดเดิม)
- ข้อดีของการแปลงที่เซิร์ฟเวอร์ครั้งเดียว (แทนที่จะให้เบราว์เซอร์แต่ละเครื่อง render เอง) คือ **ทุกคนเห็นหน้าตา
  เอกสารเหมือนกันเป๊ะ** ไม่ว่าจะเปิดจากมือถือ/iPad/PC เครื่องไหน — ขอแค่เซิร์ฟเวอร์มีฟอนต์ที่ถูกต้องตอนแปลง

## ต้องใส่ฟอนต์อะไรบ้าง

อย่างน้อยที่สุด แนะนำชุดฟอนต์ราชการไทยมาตรฐาน (ใช้กันทั่วไปในหนังสือราชการ/โรงเรียน):

- **TH Sarabun New** (หรือ TH SarabunPSK) — ฟอนต์หลักที่ใช้พิมพ์หนังสือราชการเกือบทั้งหมด
- ฟอนต์อื่นที่โรงเรียนใช้จริงในไฟล์ Word ของคำสั่ง/หนังสือต่างๆ (ถ้ามีนอกเหนือจากนี้)

**เราไม่ได้แนบไฟล์ฟอนต์มาให้ในโปรเจกต์นี้โดยตรง** เพราะไฟล์ฟอนต์เป็นงานที่มีเจ้าของลิขสิทธิ์ (แม้ชุดฟอนต์ราชการไทย
จะแจกฟรีให้ใช้งานได้ แต่การแจกต่อควรทำจากแหล่งต้นทางเพื่อให้ได้เวอร์ชันล่าสุดและถูกต้อง) ให้ดาวน์โหลดจากแหล่งทางการ
เช่น เว็บไซต์ของสำนักงานส่งเสริมเศรษฐกิจดิจิทัล/หน่วยงานราชการที่เผยแพร่ชุดฟอนต์ราชการ หรือถ้าเครื่อง Windows
ที่ใช้งานเคยติดตั้ง "ชุดฟอนต์แห่งชาติ" ไว้แล้ว ก็คัดลอกไฟล์ .ttf จาก `C:\Windows\Fonts\` มาไว้ที่นี่ได้เลย

## วิธีติดตั้ง

1. คัดลอกไฟล์ `.ttf`/`.otf` มาไว้ในโฟลเดอร์นี้ (`server/fonts/`)
2. รันสคริปต์ติดตั้งตามระบบปฏิบัติการของเซิร์ฟเวอร์:
   - **Windows** (เซิร์ฟเวอร์จริงของโรงเรียนส่วนใหญ่เป็น Windows — ดู README หัวข้อ NSSM): เปิด PowerShell
     แบบ **Run as Administrator** แล้วรัน:
     ```powershell
     cd server\scripts
     .\install-fonts.ps1
     ```
   - **Linux/Mac** (เครื่อง dev หรือเซิร์ฟเวอร์ Linux):
     ```bash
     cd server/scripts
     ./install-fonts.sh
     ```
3. รีสตาร์ท LibreOffice/เซิร์ฟเวอร์ Node แล้วลองแนบไฟล์ Word ทดสอบดูอีกครั้ง — เทียบหน้าตา PDF ที่ได้กับต้นฉบับ

## ตรวจสอบว่าเซิร์ฟเวอร์เห็นฟอนต์แล้วหรือยัง

- Windows: เปิด Settings > Fonts แล้วค้นหาชื่อฟอนต์ ควรเห็นในลิสต์
- Linux: รัน `fc-list | grep -i sarabun` ควรเจอไฟล์ที่ติดตั้งไว้
